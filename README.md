## Selected work

**[`react-gallimaps`](https://github.com/rudalkunwar/react-gallimaps)** — React components and typed hooks for the GalliMaps vector tile, geocoding and routing APIs. Published to npm as `react-gallimaps`, MIT licensed.

**[`laravel_api_only_boilerplate`](https://github.com/rudalkunwar/laravel_api_only_boilerplate)** — Typed Laravel API starter with OAuth and role-based access control already wired up.

**[`download-gdfiles`](https://github.com/rudalkunwar/download-gdfiles)** — Paste a Google Drive share link, get a direct download URL or an Office export link for Docs and Sheets.

**[`uno-multiplayer`](https://github.com/rudalkunwar/uno-multiplayer)`** — Real-time multiplayer UNO over WebSockets. Rule enforcement lives on the server, not the client, and ships inside the Next.js build.

**[`recipe-app`](https://github.com/rudalkunwar/recipe-app)`** — Recipe search that turns a list of ingredients into something you can cook.

**[`dev-portfolio-generator`](https://github.com/rudalkunwar/dev-portfolio-generator)`** — Builds a developer portfolio from a GitHub username, via the GitHub API.
